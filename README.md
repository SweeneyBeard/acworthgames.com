# acworthgames.com

Simple static website for Acworth Games, hosted with GitHub Pages.

## Publishing

Publish from the `main` branch at the repository root. The repository includes a `CNAME` file for `acworthgames.com`.

## Local preview

Open `index.html` in a browser, or serve the repository with any static file server.

## Game page and branding

- Canonical game page: `/abrecan/` (Abrecan, formerly Agnivar).
- Legacy `/agnivar/` URL remains as a static HTML redirect with a fallback link.
- The hero uses `assets/abrecan-title.png`, copied without alteration from
  `Game001/assets/Abrecan_title_512x512.png`, which originated as the supplied
  transparent `Abrecan_nobg_512x512.PNG` logo.
- Social previews and the favicon use `assets/abrecan-icon.png`, copied from
  `Game001/assets/Abrecan_icon_512x512.png`.
- Rebranding does not change game mechanics, Android platform status, or legal policies.
